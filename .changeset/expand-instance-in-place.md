Add "Expand" to the selection toolbar for a single selected instance node: unfolds that instance's own module diagram in place inside the parent canvas, recursively, with no depth cap. Boundary ports render as label-only nodes with a wire stub on each side, and each stub carries the same struct/interface/multi-bit styling as the wire it continues; wires inside the expanded module are draggable and always stay within the module's border. Drag-selection is scoped to the top-level diagram (sub-diagram content is exempt), so Auto Layout over a selection containing an expanded instance re-lays out the outer diagram and carries the expanded content along. The expanded layout persists per-instance, separately from the child module's own standalone view. Array-of-instances nodes are not yet supported (tracked in #169). A "Collapse" control in the selection toolbar reverts an expanded instance back to a normal node. The sub-diagram area inside the frame behaves like ordinary canvas — middle-drag pans there, and clicks fall through instead of grabbing the expanded instance; the frame itself is selected/dragged from its border ring (header rows, boundary-label columns, bottom inset), where its ports and instance name live. Expanding a top-level instance that grows past a neighboring block now nudges that neighbor (and anything it would in turn land on) straight down, clear of the new frame, and pins it there like a manual drag.
